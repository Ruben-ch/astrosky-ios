# AstroSky

**FR** · Application iOS d'astronomie de terrain : carte du ciel temps réel, éphémérides précises et vision nocturne rouge, utilisable de nuit et hors ligne.

**EN** · A field astronomy app for iOS: real-time sky map, accurate ephemerides and a red night-vision mode, built to work at night and offline.

---

## Fonctionnalités · Features

| | Français | English |
|---|---|---|
| 🌌 | **Carte du ciel temps réel** — étoiles Hipparcos, 88 constellations, objets Messier/NGC/IC, pilotage par boussole et gyroscope ou au doigt (glisser, pincer) | **Real-time sky map** — Hipparcos stars, 88 constellations, Messier/NGC/IC objects, driven by compass and gyroscope or by touch (drag, pinch) |
| 🔴 | **Vision nocturne rouge OLED** — palette 100 % rouge sur fond noir pur pour préserver l'adaptation à l'obscurité | **OLED red night vision** — pure red palette on true black to preserve dark adaptation |
| 🗓️ | **Éphémérides** — lever/coucher, crépuscules, phases de la Lune, conditions de la nuit, essaims météoritiques | **Ephemerides** — rise/set times, twilights, Moon phases, tonight's conditions, meteor showers |
| 🪐 | **Système solaire 3D** — positions héliocentriques réelles, rendu WebGL | **3D solar system** — real heliocentric positions, WebGL rendering |
| 🛰️ | **Suivi orbital** — radar satellites, passages visibles (ISS…), lancements à venir | **Orbital tracking** — satellite radar, visible passes (ISS…), upcoming launches |
| 📷 | **Mode caméra AR** — superposition du ciel sur l'image de la caméra avec calibration d'azimut | **AR camera mode** — sky overlay on the live camera feed with azimuth calibration |
| ⏱️ | **Machine temporelle** — horloge de simulation globale (temps réel, accéléré ou date choisie) | **Time machine** — global simulation clock (real time, accelerated or any date) |

## Stack

- **Vite** · **TypeScript** · **React** · **Tailwind CSS**
- **Capacitor** (iOS natif, Swift Package Manager) — géolocalisation, haptique, préférences
- **astronomy-engine** (mécanique céleste) · **satellite.js** (SGP4) · **Three.js** (3D)
- **Vitest** (tests) · **Oxlint** (lint) · **Playwright** (inspection visuelle iPhone)

## Démarrage · Getting started

```bash
npm install
npm run dev          # serveur de développement / dev server
npm test             # tests unitaires / unit tests
npm run lint
npm run build        # bundle web de production / production web bundle
```

### iOS

```bash
npm run build
npx cap sync ios
npx cap open ios     # ouvre le projet dans Xcode / opens the project in Xcode
```

Un workflow GitHub Actions (`.github/workflows/build-ios.yml`) produit une archive `.ipa` non signée à chaque push sur `main`.
A GitHub Actions workflow builds an unsigned `.ipa` on every push to `main`.

### Configuration

L'image astronomique du jour (APOD) utilise la clé publique `DEMO_KEY` de la NASA. Pour une clé personnelle, créez un fichier `.env.local` (non versionné) :
The Astronomy Picture of the Day uses NASA's public `DEMO_KEY`. To use your own key, create an untracked `.env.local`:

```bash
VITE_NASA_API_KEY=your_key_here
```

## Données · Data

Catalogues générés par `scripts/gen-catalogs.mjs` à partir de sources ouvertes : d3-celestial, Hipparcos, OpenNGC, GeoNames.
Catalogs are generated by `scripts/gen-catalogs.mjs` from open sources: d3-celestial, Hipparcos, OpenNGC, GeoNames.
